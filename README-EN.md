# 📹 Telegram Video Downloader

A robust Python tool for securely downloading videos from Telegram groups and channels, featuring auto-reconnection and progress tracking.

🔥 **Features**

## Bulletproof Downloading

- Automatically reconnects on connection drop  
- Configurable retry logic with exponential backoff  
- Per-file timeout control (prevents infinite hangs)

## Smart Media Management

- Filters by date/size (skips small or low-quality videos)  
- Organized storage with date-based filenames  
- Parallel download support (configurable)

## Enterprise-Grade Logging

- UTF-8 compliant logs (emoji-safe)  
- Detailed success/failure logs  
- Daily log rotation

## Security First

- Credentials stored in `.env` (never hardcoded)  
- Encrypted session handling  
- Git-safe configuration
